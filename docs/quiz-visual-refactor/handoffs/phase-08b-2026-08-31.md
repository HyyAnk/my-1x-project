## Production fixes proven by new tests

1. `buildQuizRenderStyleContext` no longer pre-resolves Channel Brand Name into the `override` layer. The shared resolver now treats blank brand values as inheritance and reports the actual Episode/Channel/Theme provenance.
2. Episode changes are split into source-affecting settings and render-style settings. Style-only changes now invalidate `render` and `qa` only; they no longer delete Quiz, Director, Assets, Asset Resolution, Voice, or Timeline artifacts.
3. `prepareQuizVideoRender` is a small production seam called by `videoRunner`. It constructs the explicit style context and delegates to the real renderer, allowing the production boundary to be tested without launching provider or FFmpeg work.

No visual matrix, CSS bundling/parity cleanup, semantic background refactor, legacy adapter cleanup, broad module splitting, migration, or new feature was included.
