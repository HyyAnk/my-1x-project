## Outcome

- Status: `COMPLETE`.
- Summary: CSS ownership boundaries (Layout, Base Component, State, Typography, Skin, Palette Tokens) are established with clean separation of concerns. A pure style-resolution policy and standardized palette token serializers in `@studio/shared` are shared across production render and web preview/sandbox. Layout CSS no longer contains selector bleed into private skin internals; skin CSS contains no outer layout placement. ## CSS ownership

| Layer          | Module/contract                                     | Owned properties/hooks                                                                                                                                                                                                    |
| -------------- | --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Layout         | `render/layouts/*.ts`                               | Stage/grid dimensions, container columns/areas, gaps, alignment, aspect-ratio rules, and capacity tokens (`--choice-card-min-height`, `--choice-badge-size`, `--choice-font-size-base`, etc.)                             |
| Base component | `render/choices/baseChoiceStyles.ts`                | Internal card flex/grid alignment, bounds, label centering, text truncate, media container, float animation hooks consuming layout capacity tokens                                                                        |
| State          | `render/choices/choiceStateStyles.ts`               | Shared reveal and settle animations (`.answer-correct`, `.answer-incorrect`, `.answer-check`, `.answer-cross`, keyframes)                                                                                                 |
| Typography     | `render/choices/choiceTypographyStyles.ts`          | Single typography tier system (`.choice-tier-*`) mapping directly to layout capacity custom properties (`--choice-font-size-*`, `--choice-label-font-size-*`)                                                             |
| Skin           | `visual/elements/answerCard/variants/*.ts`          | Borders, shadows, backgrounds, text colors, and decorative badges scoped to `.ac-*` skin classes; zero `!important` in normal cascade                                                                                     |
| Palette tokens | `@studio/shared/quizStyles.policy.ts` (serializers) | Standard semantic custom properties (`--bg-primary`, `--bg-secondary`, `--accent`, `--surface-accent`, `--on-accent`, `--answer-badge`, `--badge`, `--correct`, `--incorrect`, `--surface`, `--text`, `--ink`, `--muted`) |

## Style resolution

- Precedence implementation: Pure policy in `@studio/shared` executing `Theme defaults < Channel defaults < Selected Preset / Episode < Custom Override < Director Beat` with deterministic fallback.
- Provenance/auto handling: Tracks field-level provenance (`theme`, `channel`, `preset`, `episode`, `override`, `beat`); `auto`, `null`, and `undefined` values inherit cleanly without erasing lower layers.
- Production/Sandbox shared path: `resolveQuizStyle` and `resolveBeatQuizStyle` are used identically in web episode utilities, sandbox composition, and production server clips.
- Legacy preset adapters and removal condition: `resolvePresetPreviewLayoutId` and `adaptLegacyVisualPreset` map legacy `layout_id` to `preview_layout_id` for Sandbox showcase. Removal condition: migrate custom preset storage records to v2 and drop `layout_id`.
