# Phase 6 Handoff: New Layouts and Scalable UI

Date: 2026-08-31
Status: COMPLETE
Branch: main (uncommitted working tree with prior phases preserved)

## 1. Executive Summary

Phase 6 successfully proved the extensible visual architecture designed in Phases 1–5 by introducing two production layouts (`media_top_choices_bottom` and `full_stack_list`) for 2 and 3 choices without modifying existing auto resolution behavior (strictly enforcing ADR-006: explicit-only resolution for new layouts).

In parallel, the fixed 2-button layout selector in Visual Sandbox was refactored into a scalable, accessible, keyboard-navigable combobox/select control that dynamically scales with the layout catalog, provides immediate visual feedback, preserves latest-request-wins race protection, and maintains responsive design down to mobile widths.

---

## 2. Deliverables & Architectural Implementation

### A. Shared Schema & Capability Catalog (`@studio/shared`)

- **Schema**: Updated `QuizLayoutIdSchema` in `packages/shared/src/enums.ts` to include `"media_top_choices_bottom"` and `"full_stack_list"`.
- **Capability Catalog**: Added full capability definitions for both layouts in `packages/shared/src/quizLayouts.catalog.ts`:
  - `media_top_choices_bottom`: Text presentation, counts `[2, 3]`, formats `["multiple_choice", "image_guess", "true_false"]`, optional hero media (`media.supported: ["question"]`, `media.required: []`), metrics `{ width: 840, height: 360, itemCount: 1 }`, assets `{ question: { maxWidth: 1080, maxHeight: 608 } }`.
  - `full_stack_list`: Text presentation, counts `[2, 3]`, formats `["multiple_choice", "true_false"]`, text-only (`media.supported: []`, `media.required: []`), metrics `{ width: 1440, height: 720, itemCount: 1 }`.
- **Policy**: Enforced ADR-006 explicit-only policy in `packages/shared/src/quizLayouts.policy.ts` (`autoCandidates` restricted strictly to `["media_left_choices_right", "visual_choices_three"]`).

### B. Layout Renderers (`apps/server`)

- **`mediaTopChoicesBottom.ts`**:
  - `renderBody`: `${slots.questionBoxHtml}${slots.heroHtml}${slots.choicesHtml}<div class="phase-region">${slots.phaseHtml}</div>`.
  - Pure layout CSS publishing capacity tokens (`--choice-card-min-height`, `--choice-badge-size`, `--choice-font-size-base`, etc.) for 16:9 and 9:16 portrait. Zero `.ac-*` skin selectors.
- **`fullStackList.ts`**:
  - `renderBody`: `${slots.questionBoxHtml}${slots.choicesHtml}<div class="phase-region">${slots.phaseHtml}</div>`.
  - Pure layout CSS for full-width vertical choices without hero slot gap. Zero `.ac-*` skin selectors.
- **Registry**: Registered both renderers and their dimensions in `apps/server/src/quiz/render/layouts/registry.ts`.
- **Pipeline Integration**: Updated `resolveQuestionLayout` in `apps/server/src/quiz/layoutCompatibility.ts` and `getOptimalAssetDimensions` in `apps/server/src/tasks/video/imageOptimizer.ts` to dynamically resolve asset intents and metrics against catalog capabilities.

### C. Scalable UI & Web Integration (`apps/web`)

- **UI Catalog**: Updated `apps/web/src/features/quizLayouts/quizLayoutUiCatalog.ts` with metadata, icons, and preview keys for all 4 production layouts.
- **i18n**: Added English (`en/sandbox.ts`) and Vietnamese (`vi/sandbox.ts`) translation strings for both layouts across Visual Sandbox and Stage Studio.
- **`SandboxLayoutSelector.tsx`**: Replaced 2-button grid with an accessible, compact, keyboard-navigable combobox control with ARIA attributes (`role="combobox"`, `aria-haspopup="listbox"`, `aria-expanded`), Arrow navigation, Escape to close, active layout description subtitle, and mobile-friendly styling.
- **Stage Studio**: Added `.is-media-top` and `.is-full-stack` miniature layout preview styles in `apps/web/src/styles/features/mascot/stageStudio.css`.
- **Footer Credit**: Verified single exact responsive placement in `apps/web/src/App.tsx` (`Develop - Design - Deliver by HyyAnk | Dư Ngọc Minh Hoàng`).
