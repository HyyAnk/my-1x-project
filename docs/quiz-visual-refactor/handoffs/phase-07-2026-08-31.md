Date: 2026-08-31
Status: COMPLETE

## 1. Executive Summary

Phase 7 completes the core 7-phase Quiz Visual Refactor by establishing a typed, deterministic **Background Variant Registry** shared between production video composition (`candyArcadeClips.ts`, `candyArcadeComposition.ts`) and Visual Sandbox preview (`sandboxComposition.ts`).

Per **ADR-004 (Background as an Independent Visual Axis)**:

- The legacy background markup and animation have been extracted into the compatibility default variant `candy_rays`.
- Exactly one proof animated variant `aurora_glow` was added, featuring a soft undulating aurora mesh curtain, three luminous ambient orbs, and deterministic stardust sparkles.
- Both variants are palette-driven via CSS custom properties (`--bg-primary`, `--bg-secondary`, `--accent`, `--surface-accent`), have zero selector bleed into layout or choice cards, and provide static fallback under `@media (prefers-reduced-motion: reduce)`.
- Style resolution follows pure deterministic precedence (`Theme ("candy_rays") < Channel < Preset/Episode < Override < Beat`) without requiring migrations for legacy records.
- Background selection is fully integrated into Visual Sandbox and Episode Customization Bar using the scalable control pattern established in Phase 6.

## 2. Deliverables & Architectural Implementation

### A. Shared Schema, Style Resolution & Presets (`@studio/shared`)

- **Schema & Enums**: Added `QuizBackgroundStyleSchema` (`"auto" | "candy_rays" | "aurora_glow"`), `ALL_BACKGROUND_STYLES`, `BACKGROUND_STYLE_LABELS`, and `BACKGROUND_STYLE_DESCRIPTIONS` in `packages/shared/src/enums.ts`.
- **Contracts**:
  - `DirectorBeatSchema.background_style` defaults to `"auto"`.
  - `ChannelSchema.default_background_style` and `QuizConfigSchema.background_style` added with optional/auto defaults.
  - `SandboxPreviewInputBaseSchema.background_style`, `UpdateChannelInputSchema.default_background_style`, and `EpisodeSettingsInputSchema.background_style` updated.
- **Presets**:
  - `VisualPresetItem.background_style` added.
  - Built-in presets `preset_cyber_neon` and `preset_cosmic_space` configured with `"aurora_glow"`; other built-ins with `"candy_rays"`.
  - `matchVisualPreset` and legacy preset adapters updated to support `background_style`.
- **Style Policy (`quizStyles.policy.ts`)**:
  - `DEFAULT_QUIZ_BACKGROUND_STYLE = "candy_rays"`.
  - Pure resolver `resolveQuizStyle` / `resolveBeatQuizStyle` handles background style with complete provenance tracking (`theme`, `channel`, `preset`, `episode`, `override`, `beat`).

### B. Background Variant Registry & Scene Integration (`apps/server`)

- **Background Module (`apps/server/src/quiz/visual/elements/background/`)**:
  - `types.ts`: Defined `QuizBackgroundVariant`, `BackgroundRenderContext`, `BackgroundPerformanceMetadata`.
  - `variants/candyRays.ts`: Extracted legacy rays, rotating sprinkles, and geometric decor as the backward-compatible default variant.
  - `variants/auroraGlow.ts`: Proof animated variant with deterministic phase calculation (`questionIndex` / `ambientPhaseSeconds`), pure GPU transforms (`transform`, `opacity`), and static reduced-motion styles.
  - `registry.ts`: Single registry Map, `resolveBackgroundVariant`, `getBackgroundStylesCss`, `getBackgroundVariantCss`.
- **Scene Model & Pipeline**:
  - `quizScene.types.ts`: Added `background` to `QuizSceneElementStyles`.
  - `quizSceneStyles.ts`: Resolves background variant per beat.
  - `buildQuizSceneParts.ts` & `renderQuizSceneParts.ts`: Built and rendered via `renderQuizSceneBackground(parts, surface, context)`.
  - `candyArcadeStyles.ts`: Removed duplicate legacy CSS blocks and appended `getBackgroundStylesCss()`.
  - `candyArcadeClips.ts` & `sandboxComposition.ts`: Render identical background layers through the shared scene pipeline.
  - `legacyBackgroundAdapter.ts`: Cleanly delegates to `candy_rays`.

### C. Web UI Integration (`apps/web`)

- **Visual Sandbox**:
  - `useSandboxDesignState.ts`: Added `backgroundStyle` state and setter.
  - `useSandboxPreviewRenderer.ts`: Passes `background_style` into preview request payload with latest-request-wins race protection.
  - `SandboxDesignTab.tsx`: Added Background Variant Section with `candy_rays` and `aurora_glow` options using `SandboxStyleOptionSection`.
  - `useSandboxPresets.ts` & `useSandboxChannelSync.ts`: Preset matching/saving and channel sync modal updated with background support.
- **Episode Customization**:
  - `BackgroundDropdown.tsx`: Created dropdown component with live preview hover support.
  - `EpisodeQuizCustomizationBar.tsx`: Integrated `BackgroundDropdown` and wired `onSaveBackgroundStyle`.
  - `useEpisodeStyles.ts` & `useEpisodePipeline.ts`: Added `saveBackgroundStyle` and preset application.
  - `useEpisodeStylePreview.ts`: Resolves background style with active channel/episode context.
- **Localization**: Added English and Vietnamese translation strings in `sandbox.ts` and `episodes.ts`.
- **Footer Credit**: Preserved single exact responsive placement in `apps/web/src/App.tsx`.
