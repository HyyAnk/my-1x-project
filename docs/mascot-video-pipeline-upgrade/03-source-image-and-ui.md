# Step 2 Source Image and UI Contract

## Image composition
- Canvas is 16:9.
- Intended video input is 1280x720.
- Mascot is a large half-body subject, not a small corner mascot.
- Keep head, ears, hands and expressive features inside safe margins.
- The lower body may continue beyond the bottom edge by design.
- Use a neutral flat background chosen away from mascot colors.
- Fixed camera, identity, lighting direction and scale.
- No final bottom-left placement in the source.
- No floor, pedestal, scenery, text or frame border.

The source must read as a mascot continuing beyond the lower edge, not as a floating portrait.

## UI
Keep Concept and Add Style unchanged. Step 2 has Thinking and Celebrate tabs, ten slots per tab, source status and download actions.

On hover, keyboard focus and touch, expose:
- Download original image with background.
- Download background-removed PNG.

Both files preserve identical canvas dimensions, mascot scale, position and registration. Titles and controls use concise English labels and no trailing periods.
