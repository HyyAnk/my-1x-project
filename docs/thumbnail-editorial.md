# Editorial thumbnail generation

Auto Editorial uses one representative visual challenge, a supporting mascot reaction, and one short headline. Explicit layout overrides retain the existing preset pipeline. Existing thumbnail versions are preserved; choose Auto Editorial and Generate to create a new version.

## Interaction and state

Choose a layout, optional badge, and optional headline, then Generate. The existing thumbnail job workflow acknowledges the request immediately, prevents duplicate submissions, and reports pending, failure, retry, cancellation, and completion. Successful server results refresh the episode, history, and export. Failed or cancelled editorial generations do not publish placeholders. The existing queue and source-fingerprint guard prevent concurrent mutations or outdated episode content from replacing the current thumbnail. Desktop and mobile use the same labelled native selects and input; no essential action depends on hover.

## Responsibilities

- The AI planner selects one subject or two candidates from the same question. Its editorial response is validated at the boundary. Fallback planning remains available when the planner is unavailable.
- The editorial policy selects Big Object, Reaction, or Comparison. It removes automatic badges and answer markers. A manual headline or badge remains an explicit override.
- The art prompt directly requests native headline typography and dynamic paint brush stroke banners (top black brush banner with white lettering, bottom neon-yellow brush banner with high-contrast lettering) and circular option candidate badges.
- Sharp validates, rotates, resizes, and normalizes the generated artwork to exact output canvas geometry (1280 x 720 or 1080 x 1920) and encodes high-quality JPEG (94%), preserving the model's native artistic typography and brush textures without artificial flat SVG overlays.
- The image writer validates and normalizes before checking freshness and publishing the variant and active image. The manifest records the design template and exact headline matching the generated artwork.

## Verification and limits

Unit and integration tests cover semantic planning, typography escaping, both output ratios, image decoding, history, exports, provider failure/retry, cancellation, reuse, and stale concurrent updates. Inspect a generated image at full size and 320 x 180 before selecting it for release.

Art placement is still generated by the provider; headline pixels and output dimensions are deterministic. Candidate labels cannot guarantee that the model drew a valid puzzle, and prompt instructions cannot guarantee the absence of generated text. There is no automated vision quality score or claim of increased CTR. Compare Big Object, Reaction, and Comparison on comparable published episodes before choosing a channel default. Separate subject cutouts and automated visual QA are possible follow-up improvements.

## Live preview

Run `pnpm exec tsx scripts/preview-thumbnail-editorial.ts --live` from the project root. This sends one image-generation request through the configured provider and writes an isolated sample to `scratch/thumbnail-editorial-preview/editorial-preview.jpg`. It uses fallback planning and an unassigned default mascot; assigned channel mascots continue to use their existing reference-image flow in normal generation.
