## Specific traps that must have tests

1. `Gpti2ImageProvider.generateReference` calls `writeBundleImage` and defaults to 16:9. Do not use it for reel image storage.
2. `generateMascotAiImageBytes` currently accepts only 1:1/16:9. Its ShopAiKey branch does not forward `referenceImageBase64`. Reusing that wrapper would silently drop conditioning on that branch.
3. `generateShopAiKeyImageBytes` currently exposes text-generation options, not reference-image input. Do not advertise image-conditioning support before implementing and testing it or reject this unsupported capability explicitly.
4. `applyShortReelEdit(update_references)` currently marks the script stale. Reverse that dependency for the new workflow: script drives style; style changes only recompile prompts and invalidate cover.
5. Existing script changes do not invalidate style/cover/publishing adequately. Fingerprints alone are insufficient if edit retirement disagrees.
6. Publishing currently receives topic/source, not accepted script, and localization can overwrite the LLM description.
7. `useShortReelTaskSync` currently reloads only on task termination and filters by reel ID alone. Intermediate accepted output requires explicit refresh.
8. Cover's standalone target omits the cancellation signal in the old runner. Test every target, not only full package.
9. `runBoundedPackageProvider` clamps at 60 seconds; the configured image client may poll for several minutes. Align deadlines without removing cancellation or bounds.
10. Regenerate requests need a fresh operation ID; network replay within the same operation must retain its idempotency key. A key based only on prompt text prevents a true new variation.
11. `ShortReelRecordSchema` is strict and currently version 1. Adding fields without a legacy parser/read adapter can make the existing library disappear.
12. The route has a direct fallback without the task manager. It must use injected dependencies or return an explicit unavailable error, not manufacture successful placeholder output.
13. `shortReelTransaction.ts` is not the only record writer: `shortReels.ts` has its own create/edit calls to `writeShortReelJsonAtomic`. Upgrade backup and canonical validation must cover ordinary edits as well as generation transactions.
14. `scriptService.ts` also clamps the operation deadline to 60 seconds. Passing 90000 ms from a caller alone does not change that clamp; update and test the actual enforcing boundary.
