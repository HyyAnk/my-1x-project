# Change Request Template

Use this when an agent believes the protocol, phase scope, zone map, or ownership model must change.

```markdown
# Agent Coordination Change Request

## Request

Describe the change.

## Reason

Explain why the current protocol is insufficient.

## Affected Files

- path/to/file

## Affected Zones

- zone-name

## Risk

- low | medium | high | very-high

## Compatibility

Explain whether existing claims, prompts, or scripts remain compatible.

## Proposed Verification

- command or review step

## Integrator Decision

- approved | rejected | needs-revision
- reason
```
