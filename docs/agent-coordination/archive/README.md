# Agent Coordination Archive

This folder stores consolidated historical archives, superseded phase handoffs, and historical coordination records.

## Consolidated Handoff Archives

- **`handoffs-archive.tar.gz`**: Consolidated gzip tarball containing 344 historical agent handoffs (Phases 0–5, Refactor Waves 1–3, Short-Reel implementation repairs, and Bank/Topic workflows).
- **`handoffs-archive.zip`**: Standard zip format for Windows and native extraction tools.

## Retention Rules

- Move old handoff summaries, superseded notes, and cleanup records here when they remain useful for traceability but should not stay in the active workflow.
- Do not archive active claims, current zone maps, stable scripts, tests, or source-of-truth documents.
