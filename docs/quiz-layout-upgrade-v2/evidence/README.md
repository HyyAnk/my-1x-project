# Evidence directory

This directory initially contains templates only. It does not contain fabricated implementation evidence.

During execution, create phase-01.md through phase-12.md and FINAL-REPORT.md. Store logs and images in an explicitly scoped local artifact directory, then link their exact paths here. Avoid storing secrets, real user data or provider credentials.

Each evidence item must identify the source/build revision, fixture, command, exit code and timestamp. Before/after frames must use the same fixture and deterministic time. A screenshot with animations disabled is labeled settled geometry, never temporal proof.

Retain the latest failed attempt alongside the successful rerun when it explains a change in the plan.
