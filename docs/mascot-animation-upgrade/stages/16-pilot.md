Run one existing style with one thinking and one celebrate row, then ten variants per state. Review every contact sheet and report measured failures.

Evidence: pilot report. Stop rollout if duplicate, empty, seam or semantic QA fails.

Record changed files, commands, test output, artifacts, open risks and the next stage. Do not change a decision in the parent plan without updating the plan first.
