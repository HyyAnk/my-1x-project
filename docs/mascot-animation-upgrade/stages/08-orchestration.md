# Stage 08 — Plan and batch orchestration

## Objective

Plan style x state x slot, exactly twenty jobs per style, deduplicate by fingerprint, enforce locks, bounded concurrency, cancellation and retry.

## Completion evidence

Evidence: idempotency, race and stale-completion tests.

## Required report

Record changed files, commands, test output, artifacts, open risks and the next stage. Do not change a decision in the parent plan without updating the plan first.
