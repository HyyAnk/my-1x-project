- [ ] Add an end-to-end fixture using P0 inputs and the existing `buildApp(tempRoot)` test pattern. Submit candidates to the actual route and verify saved records, not only counters. The public route in the planning version is `POST /api/question-bank/generate-batch`, accepting `archetype_id`, `domain_id`, `subtopic_id`, `candidates`, and `persist`.

```typescript
const candidate = makeAuthorizedBankQuestion("Pikachu");
const response = await app.server.inject({
  method: "POST",
  url: "/api/question-bank/generate-batch",
  payload: {
    archetype_id: candidate.archetype_id,
    domain_id: candidate.domain_id,
    subtopic_id: candidate.subtopic_id,
    candidates: [candidate],
    persist: true,
  },
});
expect(response.statusCode).toBe(200);
const saved = await app.repository.getQuestionBankQuestion(candidate.id);
expect(saved?.question).toContain("Pikachu");
expect(saved?.choices.find((choice) => choice.id === saved.correct_choice_id)?.text).toBe("Pikachu");
```
